## Talk library canvas

`.github/extensions/talk-library/` adds a GitHub-styled **Talk library** canvas to the GitHub Copilot app. Open it from the canvas picker, or ask Copilot to "open the talk library", to browse every HTML deck in this repo and present one in place. New decks in the repo root show up automatically; titles, descriptions, and topics come from the cards in `index.html`.
